# חלק א' — הפעלה על המחשב שלך (חינם)

## שלב 1 — התקנת Node.js (פעם אחת בלבד)

Node.js הוא ה"מנוע" שמריץ את העוזר.

1. היכנס לאתר: **https://nodejs.org**
2. לחץ על הכפתור הגדול שכתוב עליו **LTS** (הגרסה היציבה).
3. פתח את הקובץ שהורד ולחץ Next / Continue עד הסוף. זהו.
4. כדי לוודא שהצליח: פתח **Terminal** (במק) או **Command Prompt** (בווינדוס) והקלד:
   ```
   node -v
   ```
   אם הופיע מספר גרסה (למשל `v20.11.0`) — מצוין, אתה מוכן.

## שלב 2 — הכנסת המפתח שלך

1. בתיקיית החבילה, מצא את הקובץ `.env.example`.
2. העתק אותו, ושנה את שם ההעתק ל־`.env` (בלי סיומת אחרת).
3. פתח את `.env` בעורך טקסט פשוט (Notepad / TextEdit).
4. בשורה `ANTHROPIC_API_KEY=` הדבק אחרי סימן ה־`=` את המפתח **החדש** שיצרת.
   דוגמה:
   ```
   ANTHROPIC_API_KEY=sk-ant-api03-המפתח-החדש-שלך
   ```
5. שמור וסגור. **הקובץ הזה נשאר רק אצלך — לעולם אל תשתף אותו.**

## שלב 3 — הפעלת העוזר

1. פתח Terminal / Command Prompt.
2. נווט לתיקיית החבילה. הדרך הקלה: הקלד `cd ` (עם רווח), גרור את התיקייה לתוך החלון, והקש Enter.
3. הקלד פעם אחת (מוריד את הרכיבים):
   ```
   npm install
   ```
   המתן שיסיים (דקה-שתיים).
4. הקלד כדי להפעיל:
   ```
   npm start
   ```
5. אם הכול תקין תראה הודעה עם:
   ```
   Open your browser at: http://localhost:3000
   API key loaded: YES ✅
   ```

## שלב 4 — שימוש

1. פתח דפדפן וכנס לכתובת: **http://localhost:3000**
2. הממשק ייפתח. בראש המסך יש מתג מקור: **Baseline / Local / Cloud**.
3. לחץ על **Local** — הנקודה לידו תהפוך לירוקה (סימן שהעוזר מחובר).
4. לחץ **REFRESH** — כעת המכרזים מגיעים בזמן אמת דרך העוזר שלך.

לכיבוי: חזור לחלון ה-Terminal והקש `Ctrl + C`.

# חלק ב' — הפעלה בענן (רץ תמיד, גם כשהמחשב כבוי)

נשתמש בשירות בשם **Render** שיש לו אפשרות חינמית למתחילים.

## שלב 1 — העלאת הקוד ל-GitHub

1. פתח חשבון חינם ב-**https://github.com**
2. צור מאגר חדש (New repository), תן לו שם למשל `astro-server`.
3. העלה אליו את כל קבצי החבילה **חוץ מהקובץ `.env`** (אותו לעולם לא מעלים).

## שלב 2 — חיבור ל-Render

1. פתח חשבון חינם ב-**https://render.com** (אפשר להתחבר עם GitHub).
2. לחץ **New +** → **Web Service** → בחר את המאגר שיצרת.
3. בהגדרות:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. גלול ל-**Environment Variables** והוסף:
   - שם: `ANTHROPIC_API_KEY` → ערך: המפתח החדש שלך.
   (כך המפתח יושב בבטחה בענן, לא בקוד.)
5. לחץ **Create Web Service**. אחרי כמה דקות תקבל כתובת כמו:
   `https://astro-server-xxxx.onrender.com`

## שלב 3 — חיבור הממשק לענן

1. פתח את הממשק (מקומית או מהכתובת בענן).
2. לחץ על כפתור ה-📡 בראש המסך.
3. בשדה **Cloud server URL** הדבק את הכתובת שקיבלת מ-Render.
4. לחץ **TEST CONNECTIONS** — הנקודה ליד **Cloud** תהפוך לירוקה.
5. לחץ על **Cloud** ואז **REFRESH** — כעת המכרזים מגיעים מהענן, 24/7.

## שאלות נפוצות

**המפתח שלי בטוח?** כן. הוא נמצא רק בקובץ `.env` (מקומי) או במשתני הסביבה של Render (ענן). הדפדפן והממשק לעולם לא רואים אותו — הם מקבלים רק תוצאות מוכנות.

**מה ההבדל בין Baseline ל-Local/Cloud?** Baseline = הנתונים המובנים, עובד תמיד גם בלי שרת. Local/Cloud = מכרזים חיים דרך העוזר שלך.

**כלום לא עובד / הנקודה אדומה?** ודא שהעוזר רץ (חלון ה-Terminal פתוח עם `npm start`), ושהכתובת בכפתור ה-📡 נכונה.

**זה עולה כסף?** Node ו-Render (בסיסי) חינמיים. התשלום היחיד הוא לפי שימוש ב-Claude API — לכן כדאי שתהיה לך מגבלת הוצאה חודשית בקונסולה.
